# Triage labels

The skills use five canonical triage roles. This file maps those roles to the labels in this repository's issue tracker.

| Canonical role    | Tracker label      | Meaning                                  |
| ----------------- | ------------------ | ---------------------------------------- |
| `needs-triage`    | `needs-triage`     | A maintainer must evaluate the issue     |
| `needs-info`      | `needs-info`       | Waiting for more details from the author |
| `ready-for-agent` | `ready-for-agent`  | Fully specified and ready for an agent   |
| `ready-for-human` | `ready-for-human`  | Requires human implementation            |
| `wontfix`         | `wontfix`          | Will not be acted on                      |

When a skill names a canonical role, use the corresponding tracker label. Edit the tracker-label column if this repository adopts different label names.
